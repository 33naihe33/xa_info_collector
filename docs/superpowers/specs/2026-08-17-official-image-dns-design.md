# 官方图片 DNS 误判修正设计

## 目标

在受控网络将官方图片域名解析到保留网段时，允许已配置白名单域名下载其图片；未在白名单中的域名与所有重定向目标继续执行严格的私网/保留地址拦截。

## 方案

`BaseAdapter._stream_download_image` 的主请求 URL 已经通过 `allowed_domains` 白名单验证。对这一初始 URL，不再因 DNS 解析结果属于私网或保留网段而拒绝；它仍必须使用 HTTP(S) 且主机名必须位于白名单。

每一个 HTTP 重定向继续运行现有地址校验：目标必须在白名单中，且解析出的地址不能是私网、回环、链路本地或保留地址。这保留了对恶意重定向的 SSRF 防护。

## 测试与补数

新增测试覆盖白名单初始域名解析到 `198.18.2.10` 时仍可下载；现有私网重定向拒绝测试保持通过。代码验证后，重新处理数据库中图片字段为空的官网文章，只回填成功下载且通过图片魔数校验的本地路径。
